# Visão geral

A Cupcake Store H transforma o backlog de uma loja de cupcakes em uma aplicação web acadêmica. O cliente consulta o catálogo, cria uma conta, monta a sacola, informa endereço e registra um pedido simulado. A administração controla produtos, estoque e andamento dos pedidos, além de consultar vendas por período.

O objetivo é demonstrar engenharia de software verificável: requisitos rastreados, persistência relacional, interface responsiva, autorização no servidor, testes e implantação reproduzível. O sistema não vende ou entrega produtos reais e não cobra pagamentos.

O planejamento anterior estabeleceu seis Epics e 17 histórias. Esta versão acrescenta implementação, banco físico, controles de acesso, testes e documentação. Resultados e limitações devem ser consultados no [laudo](laudo-qualidade.md).
